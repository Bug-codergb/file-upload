- 获取上传文件的 hash 值(通过 `SparkMD5` 获取文件的 hash 值（可以使用 WebWorker 提高获取文件 hash 值过程的性能）)
- 文件切片，将文件转为 File 对象，调用 slice 方法，(提前确定好文件切片的大小)，返回文件切片 list
- 调用后端接口，判断该 hash 值是否上传过，后端返回切片是否已经合并过，合并过则直接秒传。否则
  - 后端返回已经上传的切片序列号
  - 根据前端重新获取的所有切片，过滤出未上传的切片，进行上传
  - 使用 Promise.all 并行上传所有切片
  - 使用 promise.all 当请求数量大于 6 时，就会出现大量 pending 状态的请求，所以要控制并发请求数量
